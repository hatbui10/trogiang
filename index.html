📘 Trợ lý giải đề Tiếng Anh

Tải lên bài kiểm tra bất kỳ (ảnh chụp, PDF, Word hoặc dán văn bản) — nhận đáp án chính xác cho cả trắc nghiệm và tự luận, kèm giải thích tiếng Việt.

1 API key Google Gemini ⤒ Thu gọn

Chưa có key? Vào aistudio.google.com/apikey → đăng nhập Google → bấm "Create API key" → sao chép và dán vào ô trên. Hoàn toàn miễn phí. Key được lưu ngay trên trình duyệt của bạn (localStorage), không gửi đi đâu khác ngoài Google.

2 Đưa đề bài vào ⤒ Thu gọn

📎 Tải file / ảnh
✍️ Dán văn bản
📂 Bấm để chọn file hoặc kéo-thả vào đây
Hỗ trợ: ảnh chụp đề (JPG/PNG/WEBP), PDF, Word (.docx), .txt — có thể chọn nhiều ảnh

Nếu chế độ Mạnh nhất báo hết lượt trong ngày, trang sẽ tự chuyển sang bản Nhanh. Claude và ChatGPT bản chính thức (GPT-4/5) không có API miễn phí nên không thể thêm vào đây.

Lấy key miễn phí tại console.groq.com/keys → đăng ký → "Create API Key". Chế độ này chỉ giải được đề dán dạng văn bản.
